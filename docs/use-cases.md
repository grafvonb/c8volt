# Ops discussions

Use the [GitHub discussion board](https://github.com/grafvonb/c8volt/discussions/categories/1-use-cases-ideas) to propose or refine operational workflows. Current usage belongs in the [ops playbooks](/ops/).

| Topic | Discussion |
| --- | --- |
| Repair incidents and process instances | [Repair workflows](https://github.com/grafvonb/c8volt/discussions/189) |
| Remove orphan child instances | [Orphan cleanup](https://github.com/grafvonb/c8volt/discussions/190) |
| Remove old finished instances | [Retention policy](https://github.com/grafvonb/c8volt/discussions/191) |
| Check connection, deployment, runtime, and cleanup | [Smoke test](https://github.com/grafvonb/c8volt/discussions/56) |
| Remove selected definition versions | [Definition purge](https://github.com/grafvonb/c8volt/discussions/213) |
| Purge families selected by incidents | [Incident purge](https://github.com/grafvonb/c8volt/discussions/212) |
| Mitigate unclaimed jobs | [Stuck jobs](https://github.com/grafvonb/c8volt/discussions/238) |

Discussion proposals are not the command contract. Check command help or `c8volt capabilities --json` before using an example from an older discussion.
